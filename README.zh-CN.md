## 项目背景与核心定位 / Motivation & Overview

传统蒙古文（胡都木文，Hudum）电子语料在过去三十余年间经历了多次编码演进与厂商各自为政的字体实现——涵盖 **Unicode UTN #57**、**GB/T 25914-2023（2023 新国标）**、**GB/T 25914-2010（旧国标）**、**蒙科立 Menksoft（v1.x / v2.0）**、**奥云 Oyun（v1.x / v2.002+）**、**德力海 Delehi（v1.x / v3.0）**、**微软 Mongolian Baiti**、**蒙科立 PUA 私用区（`U+E234..`）**、**昭乌达 ZvvnMod 私用区（`U+E000..`）**、**Z52 编码**以及 90 年代的 **ASCII 键盘映射字体**。

在实际语料清洗、电子词典整理与搜索引擎构建中，**同一串 Unicode 码位在不同字体下往往呈现出截然不同的视觉字形**（例如 `U+202F + ᠶᠢᠨ` 属格后缀 `-yin` 在 UTN #57 / GB2010 下为直胫 `I`，在 GB2023 下为弯钩 `Y`；`U+202F + ᠤᠨ` 领格后缀 `-un` 是否带字冠；阴性词辅音前的 `GA` 变形及 `FVS1..FVS3` 含义等）。因此，**直接调用真实字体自身的排版表还原作者录入时看到的视觉字形**，是实现无损 UTN #57 规范化的唯一可靠途径。

Traditional Mongolian digital corpora span competing Unicode standards (`UTN #57`, `GB/T 25914-2023`, `GB/T 25914-2010`), vendor `GSUB`/`morx` implementations (`Menksoft`, `Oyun`, `Delehi`, `Mongolian Baiti`), Private Use Area fonts (`Menk-PUA`, `ZvvnMod`, `Z52`), and legacy ASCII-mapped fonts. By executing the real font file via pure-Rust HarfBuzz (`harfrust`) and mapping glyphs to `mongol-norm` written units, `mongol-font-shaper` faithfully recovers the exact visual spelling intended by the author.

## 核心特性 / Key Features

1. **纯 Rust 任意外部字体加载与塑形 (`FontShaper` / Arbitrary External Font Shaping)**  
   基于 `harfrust`（纯 Rust 版 HarfBuzz，零 C/C++ 依赖）直接执行任意 `.ttf` / `.otf` / `.ttc` 字体的 OpenType `GSUB`、Apple `AAT/morx` 状态机或纯 `cmap` 映射表。
2. **三种标准输出形态 (`mongol-norm` / Three Canonical Outputs)**（以 `default-features = false` 依赖 `mongol-norm`，不耦合内置硬编码字库）：
   - **输出 1 (`FontShaper::shape_positioned`)**：`Vec<PositionedWrittenUnit>` —— 带 `isol` / `init` / `medi` / `fina` / `control` 位置标记的精确字形单元序列；
   - **输出 2 (`FontShaper::shape_units`)**：`Vec<WrittenUnit>` —— 经位置规则折叠后与 `mongol_norm::Shaper::shape` 完全等价的书面单元序列；
   - **输出 3 (`FontShaper::normalize_text`)**：标准 **UTN #57** 蒙古文 Unicode `String` —— 自动原样保留空格、数字、标点符号以及中文、英文、西里尔文等混排文本，并支持词典中带显式 `ZWJ`（`U+200D`）的词缀词条（如 `‍ᠤᠨ`、`ᠪ‍`）。
3. **告别 SHA-256 的家族级可编辑配置 (`FontProfile` / Family-Level Editable JSON Profiles)**  
   针对同一厂商数十款字重/美术体共享同一套字形架构的特点，采用人类可读可改的 `*.profile.json`，支持 **4 级动态字形绑定**：
   - `glyph_names`（字形名称匹配，自动兼容 `uni1820.` 与 `u1820.` 等家族别名）；
   - `codepoints`（`cmap` 码位直连，专治 PUA 私用区、Z52 与老 ASCII 字体）；
   - `probes`（字符簇锚定的动态塑形探针 `ShapingProbe`，**原生通吃剥离了全部字形名的 `post v3.0` `.otf` / `.ttf` 黑盒字体**，如 Noto OTF、`DraftNew-Regular.otf`、`monbaiti.ttf`）；
   - `gid` 兜底与 `overrides` 单字体微调覆盖。
4. **多字体池错码筛查与整本词典语料投票 (`FontPool` / Multi-Font Detection & Corpus Voting)**  
   内置四维错码探针：缺字豆腐块（`NotDef`）、未消化的显式变体选择符虚线框（`VisibleFvs`）、词首/词尾非预期连写齿断裂（`ChainPositionBreak`）与未映射字形（`UnmappedGlyph`）：
   - 单条文本判别（`FontPool::detect_text`）：自动区分 **`Exact`（零分歧共识或唯一无错码胜出）** 与 **`Ambiguous`（多字体均合法但字形分歧提醒）**；
   - 语料级批量投票（`FontPool::detect_corpus` / `--corpus`）：汇总整本词典或整篇文档的错码罚分，一锤定音锁定真实录入字体（例如区分微软 Baiti、蒙科立 GB2010 与蒙科立/奥云 GB2023）。
5. **一键预生成草稿配置与本地离线竖排 SVG 标定台 (`init-map` & Calibration Studio)**  
   内置标准探针词库自动对齐 `mongol-norm` 书面单元，一键导出 `*.profile.json`，并可选生成本地离线交互式 HTML/SVG 竖排字形核对网页（支持筛选 `review=true` 待核对项并在浏览器内修改导出 JSON）。

## 命令行快速指南 / CLI Quick Guide

### 1. 编译 / Build

```bash
cargo build --release
```

### 2. 塑形与标准转换 (`shape`)

```bash
# 1) 输出标准 UTN #57 蒙古文文本（默认格式 --format text）
mongol-font-shaper shape \
  -f tests/fonts/NotoSansMongolian-Regular.ttf \
  -p utn57 \
  "《ᠮᠣᠩᠭᠣᠯ ᠤᠨ ᠪᠢᠴᠢᠭ》 — 传统蒙古文规范化"

# 2) 输出与 mongol-norm 一致的 WrittenUnit 序列（--format units）
mongol-font-shaper shape \
  -f tests/fonts/NotoSansMongolian-Regular.ttf \
  -p utn57 \
  --format units \
  "ᠮᠣᠩᠭᠣᠯ ᠤᠨ ᠪᠠᠶᠢᠨ᠎ᠠ"

# 3) 使用任意外部字体（如奥云 v2.002、蒙科立、德力海、Baiti）实时自动推断并塑形（-p auto）
mongol-font-shaper shape \
  -f "/path/to/OyunQaganTig.ttf" \
  -p auto \
  --format positioned \
  "ᠠᠬ᠎ᠠ ᠶᠢᠨ"
```

### 3. 多字体判别与整本词典投票 (`detect`)

```bash
# 单条文本多字体判别（例如检测 GB2023 格后缀 FVS3：奥云/蒙科立 2023 零错码胜出，旧国标/Baiti 因显式 FVS 被淘汰）
mongol-font-shaper detect \
  --pool "oyun2023=/path/to/OyunQaganTig.ttf:auto" \
  --pool "menk2010=/path/to/MQG8F02.ttf:auto" \
  --pool "baiti=/path/to/monbaiti.ttf:auto" \
  "ᠭᠡᠷ ᠲᠦ᠍"

# 整本词典/多行语料投票模式（--corpus），锁定整批语料所属的唯一正确字体
mongol-font-shaper detect \
  --corpus \
  --pool "utn57=tests/fonts/NotoSansMongolian-Regular.ttf:utn57" \
  --pool "oyun2023=/path/to/OyunQaganTig.ttf:auto" \
  --pool "menk2010=/path/to/MQG8F02.ttf:auto" \
  --pool "baiti=/path/to/monbaiti.ttf:auto" \
  -i "/path/to/corpus.txt"
```

### 4. 字体结构体检与映射表预生成 (`inspect` & `init-map`)


## Rust 库调用示例 / Rust API Example

```rust
use mongol_font_shaper::{DetectionStatus, FontPool, FontProfile, FontShaper};

fn main() -> Result<(), mongol_font_shaper::Error> {
    // 加载内置 UTN #57 配置与外部字体文件 / Load built-in UTN #57 profile & font
    let profile = FontProfile::builtin_utn57();
    let shaper = FontShaper::from_path("tests/fonts/NotoSansMongolian-Regular.ttf", 0, &profile)?;

    // 1. 带位置字形单元 / PositionedWrittenUnit
    let pos = shaper.shape_positioned("ᠮᠣᠩᠭᠣᠯ ᠤᠨ")?;
    assert!(pos.diagnostics.is_clean());

    // 2. 标准字形单元 / Canonical WrittenUnit
    let units = shaper.shape_units("ᠮᠣᠩᠭᠣᠯ ᠤᠨ")?;
    println!("Units: {:?}", units.value);

    // 3. 标准 UTN #57 文本（保留汉英标点透传）/ Canonical UTN #57 text
    let text = shaper.normalize_text("《ᠮᠣᠩᠭᠣᠯ ᠤᠨ ᠪᠢᠴᠢᠭ》 — UTN #57")?;
    println!("UTN #57: {}", text.value);

    // 多字体池判别 / FontPool detection
    let mut pool = FontPool::new();
    pool.push("utn57", shaper);
    let detected = pool.detect_text("ᠮᠣᠩᠭᠣᠯ")?;
    assert_eq!(detected.status, DetectionStatus::Exact);

    Ok(())
}
```
